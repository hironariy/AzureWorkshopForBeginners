# 第2回 Web 3層アプリケーション ドラフト

## 表紙

- 講座名: Azure Workshop for Beginners
- 回: 第2回
- タイトル: Web 3層アプリケーション
- 形式: オンライン座学
- 時間: 60分 (50分レクチャー、10分QA)
- 想定日: 2026年6月25日

## この回の位置づけ

第2回は、第3回から第6回で行う Azure ハンズオンの前提となる「Web アプリケーションの基本構造」を理解する回です。
受講者が Web 層、AP 層、DB 層の役割を理解し、以降の VM、コンテナ、Container Apps、PostgreSQL のハンズオンで「いまアーキテクチャのどこを作っているのか」を説明できる状態を目指します。

## 受講前提

- Azure の利用経験は不要。
- Web アプリケーション、サーバ、データベースという言葉を聞いたことがあることが望ましい。
- プログラミングやインフラ設計の詳細経験は不要。
- 第1回は最後に教材制作するため、本ドラフトでは第1回を未受講でも理解できる導入にする。

## 到達目標

- Web アプリケーションの処理が、ブラウザー、Web サーバ、アプリケーション、データベースの連携で成り立つことを説明できる。
- モノリシック構成と Web 3層アーキテクチャの違いを説明できる。
- Web 層、AP 層、DB 層の役割を説明できる。
- Azure IaaS や Azure Container Apps で Web 3層アーキテクチャを構成した場合の大まかな姿を理解できる。
- 第3回から第6回のハンズオンで何を作るのかを、Web 3層の観点で説明できる。

## 受講後に説明できること/操作できること

- Web 層、AP 層、DB 層がそれぞれ何を担当するかを説明できる。
- 静的コンテンツと動的コンテンツの違いを説明できる。
- Web サーバ、AP サーバ、DB サーバの代表的なソフトウェアをいくつか挙げられる。
- モノリシック構成の利点と注意点、Web 3層構成の利点と注意点を説明できる。
- 第3回で作る VM 上の Web サーバ、第4回で作る ACI 上の Web サーバ、第5回から第6回で作る Todo アプリの関係を説明できる。

## 本回で扱う範囲

- Web アプリケーションの基本的な処理の流れ
- モノリシック構成と Web 3層アーキテクチャ
- Web 層、AP 層、DB 層の役割
- 静的コンテンツと動的コンテンツ
- 代表的な Web サーバ、AP サーバ、DB サーバ
- Azure IaaS で Web 3層を構成する場合のサンプルアーキテクチャ
- Azure で Web 層と AP 層の可用性を高める場合の基本的な構成例
- DB 層では DB の高可用性機能や冗長化機能を利用するという基本方針
- Azure Container Apps を使う場合のサンプルアーキテクチャ
- Single Page Application の導入
- RDBMS と NoSQL の概要

## 本回で扱わない範囲

- Azure Portal の操作
- アプリケーションコードの実装
- 本番向けの詳細な可用性設計、セキュリティ設計、性能設計
- Load Balancer、Application Gateway、WAF、CDN、Private Endpoint などの詳細
- SPA の詳細設計。第9回で扱う。
- データベースのチューニング、正規化、インデックス設計
- IaC による構築

### L02-D07 リクエスト処理シーケンス

目的: Web/AP/DB が順に連携して処理する流れを説明する。

## よくある理解のつまずき

### Web 3層は必ず3台のサーバだと思ってしまう

説明方針:
Web 3層は「役割の分け方」であり、物理的なサーバ台数を直接意味するものではないと説明する。
小規模構成では同じサーバに同居することもあり、クラウドではマネージドサービスとして分かれることもある。

### Web 層と AP 層の違いが分からない

説明方針:
Web 層は利用者から見た入口、AP 層は業務処理を担当する場所として説明する。
静的な画像や HTML を返すだけなら Web 層で完結するが、ログイン、注文、Todo 作成のような処理は AP 層が関わると説明する。

### DB 層を単なるファイル置き場として理解してしまう

説明方針:
DB 層はデータを保存するだけでなく、検索、更新、整合性、同時アクセス、トランザクションなどを扱うと説明する。
詳細な DB 設計には入らず、アプリケーションにとって信頼できるデータ管理場所であることを押さえる。

### VM、コンテナ、Container Apps の違いに話が広がりすぎる

説明方針:
本回では違いの詳細に入らず、「同じ Web 3層の考え方を、異なる Azure サービスで実現できる」と説明する。
VM の詳細は第3回、コンテナの詳細は第4回、Container Apps の詳細は第5回から第6回に回す。
