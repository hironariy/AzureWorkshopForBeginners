# Edge DevTools で固定サイズのスクリーンショットを取得する Tips

Azure Portal の画面を教材用に撮影する場合は、任意の範囲選択ではなく、Microsoft Edge DevTools のビューポートサイズを固定してからスクリーンショットを取得します。これにより、HTML 版や PowerPoint 版に配置したときの余白、拡大率、トリミングをそろえやすくなります。

## 推奨サイズ

| 用途 | 推奨サイズ | 使いどころ |
| --- | --- | --- |
| 標準の横長画面 | 1600 x 900 (16:9) | Azure Portal の概要、一覧、ダッシュボード、メトリック、アラート、通常のブラウザー画面 |
| 少し縦に余裕がほしい画面 | 1440 x 900 (16:10) | 作成フォーム、設定タブ、IAM、認証、Networking、Configuration など |
| 縦長の説明素材 | 1200 x 1600 (3:4) | Review + create、長いフォーム、変数一覧、ログ詳細、設定項目が縦に多い画面 |

## 取得手順

1. Microsoft Edge で Azure Portal または対象ページを開きます。
2. DevTools を開きます。
   - macOS: `Option + Command + I`
   - メニュー: `...` > `More tools` > `Developer tools`
3. Device Toolbar を有効にします。
   - macOS: `Command + Shift + M`
   - DevTools 左上付近のスマートフォン/タブレット形のアイコンでも切り替えできます。
4. 画面上部のサイズ入力欄に、撮影したい幅と高さを入力します。
   - 例: `1600` x `900`
   - 例: `1440` x `900`
   - 例: `1200` x `1600`
5. ズーム表示が縮小されていても、ビューポートの論理サイズが指定値になっていれば問題ありません。
6. Azure Portal の左メニュー、対象ブレード、テーブル、グラフなどが意図した範囲に収まるようにスクロール位置を調整します。
7. DevTools の Command Menu を開きます。
   - macOS: `Command + Shift + P`
8. `Capture screenshot` を選択します。
   - 通常は `Capture full size screenshot` ではなく `Capture screenshot` を使います。
   - `Capture screenshot` は現在の固定ビューポート範囲だけを保存します。
9. 保存された画像を確認し、教材で見せたい部分が十分に読めるか、マスク対象が写っていないかを確認します。

## 撮影時の注意

- Azure Portal のスクリーンショットは、講座用または検証用のサブスクリプションで取得します。
- サブスクリプション ID、テナント ID、ユーザー名、メールアドレス、リソース ID、接続文字列、シークレット、課金情報、実環境名は写さないか、公開前にマスクします。
- ブラウザーのアドレスバーやブックマークバーに個人情報が出る場合は、DevTools の `Capture screenshot` でページ内だけを取得します。
- Azure Portal の UI は変わることがあるため、公開前に最新画面で取り直す必要がないか確認します。
- 文字が小さすぎる場合は、横長の全体画面にこだわらず、`1440 x 900` や `1200 x 1600` で対象ブレードを大きめに見せます。

## サイズ選びの目安

- 一覧や Overview は、まず `1600 x 900 (16:9)` で撮影します。
- 入力欄が多い作成画面は、`1440 x 900 (16:10)` を優先します。
- 下方向にスクロールしないと重要項目が見えない画面は、`1200 x 1600 (3:4)` を検討します。
- スライドで一部を拡大して使う前提の画面は、無理に全体を入れず、説明対象が読める画角を優先します。
