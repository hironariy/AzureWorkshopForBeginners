# Initial requirement for Azure Workshop beginners

## 概要

2026年6月から3か月にわたり、Azure の座学、ハンズオン、ワークショップを組み合わせた初心者向け講座を開催します。
本リポジトリではその講座で利用する教材の完成を目標とします。
本リポジトリは開発過程の資料も含むためプライベートにますが、成果物は別のパブリックリポジトリにも格納し、広く利用されることを目指します。

## 初心者向け講座の開催概要

1. オンライン講座
  - 開催日程: 2026年6月18日から9月3日までの週1回合計11回 (8月6日、13日は休み)
  - 形式: オンライン
  - 各回の時間: 1時間 (50分ほどでレクチャー、10分QAが基本構成)

2. オフライン講座
  - 開催日程: 2026年9月17日
  - 形式: オフライン
  - 時間: 4時間

### 必須要件

#### ハンズオンの内容について

- ハンズオンを行う場合は極力 Azure Portal での GUI として、IaC は絶対に使わないこと。
- どうしても Azure CLI を利用する場合は、かならず Azure Cloud Shell から利用すること。
- ハンズオンは講師が用意した Azure サブスクリプションを受講者皆で利用する。受講者は受講者ごとにリソースグループを作成する。講師は事前に受講者のユーザープリンシパルに対して、サブスクリプションをスコープとしてロールを設定しておく。ハンズオンにて権限やロールの設定方法の解説は対象外とする。

#### フォーマットについて

##### 最終成果物フォーマットと制作過程の中間成果物のフォーマット

###### 受講生向け

最終成果物は PowerPoint のスライド形式とする。最終成果物に至るまでの過程で下記のように段階的に中間成果物を作成し、内容をチェックする。

1. Markdown 形式の詳細まで記述した中間成果物。
2. Microsoft 365 Cowork に参考資料として渡すための、1のMarkdown のコンテンツをベースとした、Marp 形式の中間成果物、およびの PowerPoint を Cowork に作成させるためのプロンプト。
3. 2の Marp 形式の中間成果物をベースに Microsoft 365 Cowork が作成した最終成果物となる PowerPoint スライドファイル。

###### 講師向け

講師向けには Markdown 形式の事前準備物などを示した資料を回ごとに用意する。
受講生向け教材を踏まえて強調するべきポイントや特に丁寧に解説するべきポイントを示す。

##### 言語

日本語で開発する。完成後、完成度が良ければ英語版を作成する。

##### アクセシビリティ

2および3で作成する中間成果物、最終成果物のスライドはアクセスビリティに配慮した色合い、文字の大きさとすること。

##### セクション分け

セクションを適切に分割し、各セクションの最初にはセクションタイトルスライドを挿入すること。

##### コンテンツスライド構成

- 解説、説明資料はリード文を必ず挿入し、そのスライドの要旨を記述すること。
- リード文の配下には図表を挿入すること。Azure Portal など操作の解説に必要なスクリーンショットが必要な場合は必ず、筆者に対してどのようなスクリーンショットを取るべきか指示し、いい加減な図表を埋めないこと。
- ハンズオンの手順を示す資料の場合は全面的にスクリーンショットをはり、吹き出しで操作箇所を示すもので良い。スクリーンショットは筆者が取得するので、吹き出しに各内容を AI で記述すること。

##### 図表

- スクリーンショットではなく、図表とする場合はできる限り AI で作成すること。
- 特に図を必要とする場合は、draw.io の MCP サーバを利用して図を書くことを検討し、作成方法をプランニングしてから図の作成を開始すること。
- 図を作成したら svg 形式でエクスポートし、スライドに挿入すること。
- Azure のアイコンはインラインSVGではなくdraw.io内蔵のAzure SVGアイコンをimg/lib/azure2/の参照パスで指定すること。
- アイコンのテキストの背景色は設定しないこと。
