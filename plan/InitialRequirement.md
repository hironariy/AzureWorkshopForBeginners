# Initial requirement for Azure Workshop beginners

## 概要

2026年6月から3か月にわたり、Azure の座学、ハンズオン、ワークショップを組み合わせた初心者向け講座を開催します。
本リポジトリではその講座で利用する教材の完成を目標とします。
本リポジトリは開発過程の資料も含むためプライベートにしますが、成果物は別のパブリックリポジトリにも格納し、広く利用されることを目指します。

## 初心者向け講座の開催概要

1. オンライン講座
  - 開催日程: 2026年6月18日から9月3日までの週1回合計11回 (8月6日、13日は休み)
  - 形式: オンライン
  - 各回の時間: 1時間 (50分ほどでレクチャー、10分QAが基本構成)
  - 最大受講者数: 50名

2. オフライン講座
  - 開催日程: 2026年9月17日
  - 形式: オフライン
  - 時間: 4時間

## 想定する受講者のレベル

- AWS の経験は問わない。AWS 未経験者も受講可能。ただし、オンプレミスでのシステム開発か Azure でのシステム開発のどちらかは経験していること。
- Azure はまったく触ったことがなくても受講可能
- Web アプリケーション、サーバ、ネットワーク、データベースという用語を聞いたことがある受講者を想定する。詳細な設計経験や運用経験は必須としない。
- ハンズオンでは Azure Portal、Web ブラウザー、GitHub、Azure Cloud Shell を利用する可能性がある。第5回から第6回では受講者個人の GitHub アカウントを利用する。受講者が所属組織の端末やネットワーク制限により利用できない場合は、講師が代替手順またはデモ手順を用意する。

## 講座全体の到達目標

- Azure の主要なサービスカテゴリを、アプリケーション実行基盤、データ、ネットワーク、ID、セキュリティ、監視、AI の観点で整理して説明できるようになる。
- Azure Portal を使って基本的なリソースを作成し、作成したリソースの役割、接続関係、削除方法を理解できるようになる。
- Web 3層アーキテクチャ、コンテナを利用した構成、SPA/静的 Web サイト構成の違いを説明できるようになる。
- Cloud Adoption Framework、Well-Architected Framework、Azure Landing Zone の位置づけを理解し、クラウド設計において設計原則、運用、セキュリティ、コストを考慮する必要があることを説明できるようになる。
- ハンズオンで構築したリソースについて、課金が発生するポイント、停止できるリソース、削除すべきリソースを判断できるようになる。

## 教材設計の共通方針

各回の教材ドラフトでは、原則として次の項目をそろえて記述する。初期要件の段階で未確定の項目は、無理に決め打ちせず「未決事項」に記録し、教材作成時に確定する。

- 目的: その回を講座全体の中で実施する理由を示す。
- 受講前提: 受講者が事前に理解していること、完了しているハンズオン、必要なアカウントや権限を示す。
- 到達目標: その回の終了時点で理解してほしい概念や考え方を示す。
- 受講後に説明できること/操作できること: 受講後に口頭で説明できる内容、または Azure Portal などで操作できる内容を示す。
- 扱う範囲: その回で必ず扱うサービス、概念、操作を示す。
- 扱わない範囲: 時間内では深掘りしない内容、上級者向けとして扱わない内容、別回に回す内容を示す。
- 成果物: 受講者が作成する Azure リソース、確認するアプリケーション、理解したアーキテクチャ図、講師向け準備資料などを示す。
- 講師準備: 講師が事前に作成、確認、配布、検証しておくものを示す。
- 受講者作業: 受講者が講座中に実施する操作、確認、メモする値を示す。
- 確認ポイント: 受講者が到達目標に達したことを確認するための質問、画面、URL、ログ、リソース状態を示す。

##### 命名規則

- 受講者番号は講師が事前に採番し、`s01`、`s02` のような形式で受講者に割り当てる。
- リージョンは原則として `Japan East` を利用する。Static Web Apps のように `Japan East` を利用できないサービスでは、`Japan East` にもっとも地理的に近い利用可能リージョンを利用する。対象サービスが `Japan East` で利用できない、またはクォータ上の理由で利用が難しい場合は、講師が代替リージョンを指定し、教材中に明記する。

- リソース名には、可能な限り講座名を示す `azbeg`、回番号、受講者番号を含める。ただし、Azure Container Registry などリソース名にハイフンを使えないサービスでは、各サービスの命名制約を優先する。
- すべてのハンズオン用 Azure リソースには、可能な限り `Course=AzureWorkshopForBeginners`、`Lesson=L<回番号>`、`StudentId=<受講者番号>`、`Environment=Workshop`、`DeleteAfter=<削除予定日>` のタグを設定する。
